Kubernetes is a container orchestration platform used to manage containers at scale.
Kubernetes (K8s) is an open-source container orchestration platform originally developed by Google, now maintained by the Cloud Native Computing Foundation (CNCF).

Here's a solid overview:

## Core Concept
Kubernetes automates the deployment, scaling, and management of containerized applications. Think of it as an operating system for your cluster of machines.

## Key Components

**Control Plane**
- **API Server** – the front door; all communication goes through it
- **etcd** – distributed key-value store holding all cluster state
- **Scheduler** – decides which node runs which pod
- **Controller Manager** – maintains desired state (e.g., keeps 3 replicas running)

**Worker Nodes**
- **kubelet** – agent on each node that talks to the control plane
- **kube-proxy** – handles networking rules
- **Container runtime** – actually runs containers (containerd, CRI-O, etc.)

## Core Objects
- **Pod** – smallest deployable unit; wraps one or more containers
- **Deployment** – manages rolling updates and replica sets
- **Service** – stable network endpoint for a set of pods
- **ConfigMap / Secret** – externalize configuration and sensitive data
- **Namespace** – virtual cluster for isolation
- **Ingress** – routes external HTTP/S traffic to services
- **PersistentVolume (PV/PVC)** – storage abstraction

## What It Solves
- **Self-healing** – restarts failed containers, replaces unhealthy nodes
- **Horizontal scaling** – scale up/down manually or automatically (HPA)
- **Rolling deployments** – zero-downtime updates with easy rollbacks
- **Service discovery & load balancing** – built-in DNS and traffic routing
- **Resource management** – CPU/memory requests and limits per container

## Common Ecosystem Tools
| Tool | Purpose |
|---|---|
| Helm | Package manager (charts) |
| kubectl | CLI to interact with clusters |
| Prometheus + Grafana | Monitoring & dashboards |
| Istio / Linkerd | Service mesh |
| ArgoCD / Flux | GitOps & continuous delivery |
| cert-manager | TLS certificate automation |

## Where It Runs
- **Managed**: GKE (Google), EKS (AWS), AKS (Azure)
- **Self-hosted**: kubeadm, k3s (lightweight), RKE
- **Local dev**: minikube, kind, Docker Desktop

## When *Not* to Use It
Kubernetes has real operational overhead. For small apps, simple workloads, or small teams, alternatives like Docker Compose, Railway, Fly.io, or plain serverless may be more practical.
